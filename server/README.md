# خادم DUGY على الراسبيري

خادم صغير يمرّر الرسائل المشفّرة بين الهواتف فورًا **ولا يحفظ أي رسالة**.
يحفظ فقط: الحسابات (بصمة كلمة المرور)، والمفاتيح العامة، ورموز الدعوة.
يستمع على 127.0.0.1 فقط، ويصل إليه الأعضاء عبر شبكة Tailscale الخاصة (`tailscale serve`).

- `dugy_server.py` الخادم (Python + aiohttp + SQLite).
- `install.sh` قالب التثبيت؛ يُدمج فيه الخادم عند البناء فيصبح `dugy-install.sh` المرفق مع كل إصدار.
- `test_server.py` اختبار يُشغَّل في كل بناء.

بعد التثبيت ضع العنوان الذي يظهر في `server.properties` في جذر المستودع.
لإنشاء رمز دعوة: `sudo dugy-invite`.
