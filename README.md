# DUGY — مراسلة خاصة (Android)

> **الحالة: نموذج أولي — لا يرسل رسائل مشفرة فعليًا.**
> هذا الإصدار هو المرحلة الأولى من وثيقة المتطلبات، ومعها الحمايات المحلية الحقيقية.
> لا يملك التطبيق إذن الوصول إلى الإنترنت أصلًا، ولا يصلح لمحادثات حساسة قبل تنفيذ المرحلة الثانية واجتياز مراجعة أمنية مستقلة.

تطبيق أندرويد عربي باتجاه RTL، بلغة Kotlin وJetpack Compose. يجمع قسم «الخواطر» وقسم «المحادثات الخاصة» الظاهر بوضوح، بهوية بصرية مستقلة.

## البناء والتشغيل

- يبني GitHub التطبيق تلقائيًا عند كل رفع إلى الفرع `main` (الملف `.github/workflows/build.yml`).
- ملف التثبيت الجاهز يظهر في صفحة **Releases** باسم `DUGY.apk`، تحت الإصدار `latest`.
- سجل آخر عملية بناء يُحفظ في الفرع `ci-logs`.
- للتحديث من الهاتف: ارفع ملفًا مضغوطًا باسم `dugy-update.zip` إلى جذر المستودع، فيفكّه سير العمل ويحفظ الملفات ثم يبني التطبيق.
- يمكن أيضًا فتح المشروع في Android Studio وتشغيله على جهاز بنظام Android 8.0 (API 26) فما فوق.

## ما الذي يعمل في هذا الإصدار

| المتطلب | الحالة | أين في الشفرة |
|---|---|---|
| واجهة عربية RTL وهوية مستقلة | منفّذ | `ui/theme/Theme.kt` |
| قسم الخواطر (مفضلة، نسخ، خاطرة اليوم) | منفّذ (خواطر أصلية) | `ui/quotes/`, `data/Quotes.kt` |
| قسم «المحادثات الخاصة» ظاهر | منفّذ | `ui/main/MainContent.kt` |
| إنشاء محادثة وكتابة نص حر بالعربية والإنجليزية | منفّذ | `ui/chats/` |
| تخزين محلي مشفّر (AES-256-GCM) | منفّذ | `data/ChatRepository.kt`, `security/AesGcm.kt` |
| مفتاح البيانات محمي برمز القفل + Android Keystore (StrongBox إن توفر) | منفّذ | `security/Vault.kt`, `security/KeystoreCipher.kt` |
| رمز قفل بلوحة أرقام داخلية، PBKDF2، تأخير متصاعد | منفّذ | `ui/lock/`, `security/PinKdf.kt` |
| فتح بالبصمة مرتبط بمفتاح Keystore (CryptoObject) | منفّذ | `security/BiometricAuth.kt` |
| قفل تلقائي (فورًا / دقيقة / ٥ دقائق) | منفّذ | `security/LockManager.kt` |
| مسح بعد محاولات فاشلة (اختياري، معطّل افتراضيًا) | منفّذ | `security/Vault.kt` |
| `FLAG_SECURE` وإخفاء المعاينة في التطبيقات الأخيرة | منفّذ (قابل للتعطيل بتأكيد) | `MainActivity.kt` |
| استبعاد النسخ الاحتياطي والنقل بين الأجهزة | منفّذ | `AndroidManifest.xml`, `res/xml/` |
| إشعارات عامة افتراضيًا + خيارات + نسخة عامة لشاشة القفل | منفّذ (مع زر إشعار تجريبي) | `notify/Notifier.kt` |
| رسائل مؤقتة (محليًا) وحذف رسالة أو محادثة بنطاق واضح | منفّذ محليًا | `data/ChatRepository.kt` |
| حذف كل البيانات (مسح تشفيري للمفاتيح) | منفّذ | `LockManager.wipeEverything` |
| شاشة «حدود الحماية» | منفّذ | `ui/settings/ThreatModelScreen.kt` |
| لا تحليلات، لا تقارير أعطال، إزالة `Log` من نسخة الإصدار | منفّذ | `app/build.gradle.kts`, `proguard-rules.pro` |
| **إرسال واستقبال بتشفير طرفي** | **غير منفّذ** | المرحلة الثانية |
| **التحقق من مفاتيح جهات الاتصال (رمز أمان/QR)** | **غير منفّذ** (شاشة توضيحية فقط) | المرحلة الثانية |
| **الحسابات وإدارة الأجهزة والخادم** | **غير منفّذ** | المرحلة الثانية |

## البنية

```
app/src/main/java/app/dugy/
├── DugyApp.kt / MainActivity.kt / AppContainer.kt
├── security/   Vault, KeystoreCipher, PinKdf, AesGcm, BiometricAuth, LockManager
├── data/       Models, ChatRepository (مخزن مشفّر), StoreCodec, SettingsStore,
│               MessageTransport (نقطة ربط المرحلة الثانية), Quotes
├── notify/     Notifier
└── ui/         onboarding, lock, main, quotes, chats, settings, theme, components
```

نقطة الربط الوحيدة للمرحلة الثانية هي واجهة `MessageTransport`. التنفيذ الحالي `PrototypeTransport` لا يرسل شيئًا، ويعيد الحالة «محفوظة محليًا — لم تُرسل». الواجهة تعرض شريط «نموذج أولي» ما دام `isEndToEndEncrypted = false`.
