# DUGY — مراسلة خاصة (Android)

> **الحالة: إصدار تجريبي.** الرسائل مشفّرة تشفيرًا طرفيًا بمكتبة Signal الرسمية (libsignal 0.106.1).
> لم يخضع التطبيق بعد لمراجعة أمنية مستقلة.

تطبيق أندرويد عربي باتجاه RTL، بلغة Kotlin وJetpack Compose. يجمع قسم «الخواطر» وقسم «المحادثات الخاصة» الظاهر بوضوح، بهوية DUGY البصرية.

- تفاصيل التشفير والاختبارات: [docs/E2E.md](docs/E2E.md)
- ربط الخادم: [docs/FIREBASE_SETUP.md](docs/FIREBASE_SETUP.md)
- حدود الحماية: [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md)
- الترخيص: AGPL-3.0 (يفرضه ترخيص libsignal)

## البناء والتشغيل

- يبني GitHub التطبيق تلقائيًا عند كل رفع إلى الفرع `main` (الملف `.github/workflows/build.yml`).
- ملف التثبيت الجاهز يظهر في صفحة **Releases** باسم `DUGY.apk`، تحت الإصدار `latest`.
- سجل آخر عملية بناء يُحفظ في الفرع `ci-logs`.
- للتحديث من الهاتف: ارفع ملفًا مضغوطًا باسم `dugy-update.zip` إلى جذر المستودع، فيفكّه سير العمل ويحفظ الملفات ثم يبني التطبيق.
- يمكن أيضًا فتح المشروع في Android Studio وتشغيله على جهاز بنظام Android 8.0 (API 26) فما فوق.

## البنية

```
app/src/main/java/app/dugy/
├── DugyApp.kt / MainActivity.kt / AppContainer.kt
├── e2e/        DugySignalStore, E2eEngine        (التشفير الطرفي عبر libsignal)
├── net/        FirebaseRelay, Messenger, Connectivity   (الخادم ومسار الإرسال والاستقبال)
├── security/   Vault, KeystoreCipher, PinKdf, AesGcm, BiometricAuth, LockManager
├── data/       Models, ChatRepository (مخزن مشفّر), StoreCodec, SettingsStore, Quotes
├── notify/     Notifier
└── ui/         onboarding, lock, account, main, quotes, chats, settings, theme, components
firebase/firestore.rules   قواعد أمان قاعدة البيانات
```
