# خطة الاختبار اليدوي (على جهاز حقيقي)

استخدم نسخة debug للفحوص التي تحتاج `run-as`، ونسخة release لفحص السجلات.
معرّف الحزمة: `app.dugy.messenger`

## 1. القفل والرمز

| الخطوة | المتوقع |
|---|---|
| تثبيت جديد ← الشاشة التعريفية ← إنشاء رمز من 6 أرقام وتأكيده | فتح التطبيق على تبويب الخواطر |
| إدخال رمز تأكيد مختلف | رسالة «الرمزان غير متطابقين» والعودة للبداية |
| مغادرة التطبيق والعودة (الإعداد: فورًا) | شاشة القفل |
| إدخال رمز خاطئ 5 مرات | انتظار 30 ثانية مع عدّاد، ولوحة الأرقام معطّلة |
| خطأ سادس بعد انتهاء الانتظار | انتظار 60 ثانية |
| تفعيل «المسح بعد 10 محاولات» ثم 10 أخطاء | مسح كامل والعودة إلى الشاشة التعريفية |
| «نسيت الرمز؟» | شرح عدم إمكان الاستعادة، وخيار المسح فقط |
| تغيير الرمز ثم القفل والفتح بالرمز الجديد | يفتح، وتبقى المحادثات |

## 2. البصمة

| الخطوة | المتوقع |
|---|---|
| تفعيل البصمة من الإعدادات | تظهر نافذة النظام، ثم يصبح المفتاح مفعّلًا |
| القفل والعودة | تظهر نافذة البصمة تلقائيًا، وتفتح التطبيق |
| إضافة بصمة جديدة من إعدادات الجهاز ثم العودة | تُعطَّل البصمة مع رسالة توضيحية، ويعمل الرمز |

## 3. التخزين المشفّر

```bash
adb shell run-as app.dugy.messenger ls -la files shared_prefs
adb shell run-as app.dugy.messenger cat files/chats.bin | xxd | head
# ابحث عن عبارة اختبار كتبتها في رسالة:
adb shell run-as app.dugy.messenger cat files/chats.bin | grep -c "عبارة_اختبار"   # المتوقع 0
adb shell run-as app.dugy.messenger cat shared_prefs/vault.xml   # أغلفة base64 فقط، لا رمز
```

## 4. النسخ الاحتياطي

```bash
adb shell bmgr enable true
adb shell bmgr backupnow app.dugy.messenger
```

المتوقع: لا تُنسخ أي بيانات، لأن `allowBackup=false` وقواعد الاستبعاد تشمل كل النطاقات. تحقق أيضًا من أن التطبيق لا يظهر ضمن التطبيقات التي لها نسخة احتياطية في إعدادات Google بالجهاز. جرّب كذلك النقل بين جهازين (device-to-device) إن أمكن، وتأكد من عدم نقل المحادثات.

## 5. لقطات الشاشة والتطبيقات الأخيرة

| الخطوة | المتوقع |
|---|---|
| لقطة شاشة داخل أي شاشة | يرفض النظام اللقطة |
| تسجيل الشاشة | يظهر التطبيق أسود في التسجيل |
| فتح التطبيقات الأخيرة | معاينة فارغة |
| تعطيل الحماية من الإعدادات (يتطلب تأكيدًا) | تُسمح اللقطات |

## 6. الإشعارات

| الإعداد | داخل اللوحة والهاتف مفتوح | على شاشة القفل |
|---|---|---|
| إخفاء كل التفاصيل | «لديك رسالة جديدة» | «لديك رسالة جديدة» |
| اسم المرسل فقط | الاسم + «رسالة جديدة» | «لديك رسالة جديدة» |
| الاسم والنص (بتأكيد) | الاسم + النص | «لديك رسالة جديدة» |

استخدم زر «عرض إشعار تجريبي». على أندرويد 13 فما فوق يُطلب إذن الإشعارات أولًا.

## 7. السجلات والشبكة

```bash
adb logcat -c
# اكتب رسائل وأرسلها، وأقفل التطبيق وافتحه
adb logcat -d | grep -i "عبارة_اختبار"    # المتوقع: لا شيء
adb shell dumpsys package app.dugy.messenger | grep -i "android.permission.INTERNET"   # المتوقع: لا شيء
```

## 8. الواجهة

- غيّر لغة الجهاز إلى الإنجليزية: تبقى الواجهة عربية RTL.
- اكتب رسالة إنجليزية: تُحاذى حسب اتجاه نصها.
- كبّر حجم الخط من إعدادات الجهاز: لا يُقص النص في الشاشات الرئيسية.
- جرّب الوضع الليلي.
- الرسائل المؤقتة: اختر «يوم واحد» ثم قدّم ساعة الجهاز يومًا. المتوقع حذف الرسائل الأقدم خلال 30 ثانية من فتح المحادثة.
